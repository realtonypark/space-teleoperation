# space-teleoperation

Research program and testbed for teleoperating simple robot arms inside a LEO satellite to collect
physical-AI demonstration data. See `docs/PROGRAM.md` for the charter, `docs/research/` for findings,
`docs/hypotheses/` for the ranked idea pool, `docs/experiments/` for results, and `docs/REPORT.md`
for the final report.

```
uv sync
uv run pytest -q
```
